First public release. The package was extracted from the private HyperCarrier
repository, where it was `@hypercarrier/durable-rarebit`.

- Selects Rarebit evidence (user prose, tool-use continuations, stops) from
  the full pi-durable history, so compaction never hides it.
- Derives Summary and Title receipts through an injected model call.
- Provides the `rarebit_recall` tool and the `rarebit` prompt section.
- Needs pi-durable 1.4.0 and `@hypercarrier/rarebit` 0.5.2, both pinned exactly.

This version was published by hand and has no npm provenance. Later versions
publish from CI with provenance.
